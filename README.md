
# Ejercicios Python 2

## Ejercicios

1. **Ejercicio 1** crear una lista de números del 1 al 100 y mostrarla en orden inverso.
2. **Ejercicio 2** generar una lista de números aleatorios y mostrar su tamaño.
3. **Ejercicio 3** introducir palabras, modificar la central, buscar una palabra y seleccionar una aleatoria.
4. **Ejercicio 4** calcular el IMC a partir del peso y la estatura.

## Ejecución

Ejecutar cada ejercicio desde la terminal:

```powershell
python ejercicio1.py
python ejercicio2.py
python ejercicio3.py
python ejercicio4.py
```
